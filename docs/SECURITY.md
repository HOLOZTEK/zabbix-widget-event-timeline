# Security Policy

## Supported Versions

Security fixes are prepared for the latest published version of Event Timeline.

## Reporting a Vulnerability

Do not disclose suspected vulnerabilities in a public issue before maintainers have had time to assess them.

Please report suspected vulnerabilities privately through GitHub private vulnerability reporting:

https://github.com/HOLOZTEK/zabbix-widget-event-timeline/security/advisories/new

Include:

- affected version
- Zabbix and PHP versions
- reproduction steps
- expected impact
- relevant logs or screenshots with credentials, internal URLs, and personal data removed

Maintainers will review the report, determine impact, and coordinate a fix or disclosure plan.
