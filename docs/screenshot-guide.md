# Screenshot Guide

The initial public staging page intentionally contains no screenshots.

When screenshots are added later, use a demo Zabbix environment and sanitized data. Do not use production dashboards or real monitoring data.

Recommended future files:

- event-timeline-dashboard-overview.png
- event-timeline-tooltip.png
- event-timeline-by-host.png
- event-timeline-by-host-group.png
- event-timeline-by-event.png
- event-timeline-drilldown.png
- event-timeline-settings-en.png
- event-timeline-settings-ja.png
- event-timeline-navigator-integration.png

Remove or crop browser address bars, usernames, internal URLs, IP addresses, customer names, organization names, and production dashboard titles. Use neutral demo hosts such as web-01 and db-01. Keep dashboard screenshots readable at a README display width of approximately 750 pixels and settings screenshots readable at approximately 620 pixels.
